## Ключевые проекты

### [Coal Shipment Control](https://github.com/realht/coal-shipment-control)

Система учёта автомобильных и железнодорожных отгрузок, разработанная для замены общего Excel-файла многопользовательским веб-приложением.

Реализованы роли и права доступа, импорт и экспорт Excel, работа с документами, журналирование действий, поиск, фильтрация, резервное копирование и восстановление.

**Стек:** Python, Django, MariaDB, Docker, Gunicorn, Tailwind CSS, pytest, Playwright.

Публичный репозиторий содержит согласованную заказчиком демонстрационную версию на основе одного из предыдущих релизов. Актуальный коммерческий продукт внедрён и эксплуатируется на инфраструктуре заказчика. Исходный код актуальной версии, реальные данные и внутренняя документация заказчика не публикуются.

### [OpenClaw Telegram RAG](https://github.com/realht/openclaw-telegram-rag)

Локальная система тематической памяти для Telegram и OpenClaw.

Поддерживает сохранение задач, заметок, идей и документов, семантический и ключевой поиск, использование найденного контекста, архивирование и управление данными через web-интерфейс.

**Стек:** Python, FastAPI, Chroma, Ollama, React/Vite, Docker, Telegram, OpenClaw.

Приватная рабочая конфигурация развёрнута на VPS и используется как персональный AI-ассистент. Публичный репозиторий содержит очищенную переносимую версию без пользовательских данных, секретов и приватных настроек.

### [Асинхронный HTTP-сервер](https://github.com/realht/cpp-http_async_server)

Асинхронный сервер на C++ с использованием Boost.Asio и PostgreSQL. Реализованы обработка параллельных запросов, сохранение состояния и восстановление после сбоев.

### [Консольная электронная таблица](https://github.com/realht/cpp-spreadsheet_in_console)

Табличный процессор на C++ с формулами, графом зависимостей, кэшированием вычислений и обнаружением циклических ссылок.

### [Транспортный справочник](https://github.com/realht/cpp-transport_app)

Система построения маршрутов на C++ с графовой моделью, алгоритмом Дейкстры, JSON-интерфейсом и SVG-визуализацией.
